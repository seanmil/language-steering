# language-steering

This holds issues for the Language Steering project.
If you have suggestions, please add them here as issues.

* DSL language changes, including new constructs or changing behaviour
* New or updated facts or fact values
* Core product changes, like new settings or the like
* Proposed deprecations

The committee will discuss and refine suggestions.
Not all will be accepted and many will be significantly refactored.
Once completed, they'll be prioritized and grouped into language revision milestones, which can also be seen in this repository's [milestones view](https://github.com/voxpupuli/language-steering/milestones).
Any dates included should be taken as advisory and aspirational, not as engineering committments.

## Meetings

Meeting agenda, schedules, and notes can be seen in the wiki for this repo.
